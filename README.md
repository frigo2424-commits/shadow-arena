# Pokémon Shadow Arena

Jeu de combat Pokémon à la Dislyte, version application.

**Jouer :** https://frigo2424-commits.github.io/shadow-arena/

Sur téléphone : ouvre le lien dans Chrome, puis menu ⋮ → « Installer l'application » (ou « Ajouter à l'écran d'accueil ») pour avoir l'icône et le plein écran en paysage.

Ce dépôt contient uniquement le jeu compilé (généré depuis le dépôt de développement).
